# Limiar

Simulador educativo sobre emergência climática, feito com React e Vite. A experiência reúne uma missão de resposta a uma onda de calor e um laboratório simplificado de cenários de políticas climáticas.

## Executar localmente

```sh
npm install
npm run dev
```

## Verificações

```sh
npm run build
npm run lint
```

## Sobre as projeções

O modo de políticas usa relações simplificadas para fins educativos. Ele não reproduz o modelo científico do En-ROADS e não deve ser interpretado como previsão climática.
